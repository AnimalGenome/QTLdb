# Release 59

(Apr 20, 2026)

A sum of <B>7,562</B> new QTL/associations have been curated into the 
database. (New additions less obsolete/retracted ones: <I>Cattle: 5,291; 
Chicken: 1,137; Goat: 322; Horse: 0; Pig: 173; Sheep: 639; Rainbow 
trout: 0</I> -- Net increase: <B>7,562</B>).

To date, the current total number of QTL in the database: 318,441
\[Breakdown by species -- Cattle: 212,372 (on 572 traits);
Chicken: 30,465 (on 244 traits); Goat: 3,115 (on 92 traits); Horse: 2,545 
(on 71 traits); Pig: 58,517 (on 410 traits); Sheep: 9,226 (on 191 traits); 
Rainbow trout: 2,201 (on 35 traits)\]</span> curated from 3,038 publications.

In addition, data updates were made to about 1,097 QTL/associations, 67 base 
traits, and 39 trait variants, partly as a result of active developments 
of trait ontologies (VT, LPT, CMO). Base trait updates by species -- cattle:
17; chicken: 18; goat: 4; pig: 173; horse: 3; pig: 15; sheep: 10.

## Disclaim

This data is provided "as is" with NO warranty, for the sole purpose of research use only. Please note these genome 'bp' coordinates situations:

The genome build (or "maps), to which the original QTL/association data were curated to, is called "primary build". The curated data have been liftover to "other builds" by an NAGRP in-house procedure/pipeline based on stable SNP re-mappings.
